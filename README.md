# Напальчик

Цветная браузерная аркада: ловите попугаев на палец. Один попугай — одно очко, три промаха — конец игры.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки: `npm run build`. Собранные файлы появятся в каталоге `dist`.

## Публикация

Игра опубликована через GitHub Pages: <https://vulpeculab.github.io/napalchik/>.

После отправки изменений в ветку `main` workflow `.github/workflows/deploy.yml` автоматически собирает и публикует новую версию. В настройках репозитория (**Settings → Pages → Build and deployment**) должен быть выбран источник **GitHub Actions**.

## Управление

- `Q` / `E` — левая / правая верхняя рука
- `A` / `D` — левая / правая нижняя рука
- `←` / `→` — сторона, `↑` / `↓` — высота
- `P` или `Esc` — пауза
- На сенсорных экранах коснитесь нужной четверти игрового поля

Звук можно отключить. Лучший результат сохраняется локально в браузере.
